IT Help Desk Ticket System — Architecture Overview

A high-level, layered view of the system's building blocks and how a request travels from the user through the Laravel application to the database and back. Each layer is drawn as a band; arrows show the direction of the main data flow.

LAYER 5
External Services
Outside the application

Gmail (SMTP / IMAP)

Receives email-tickets; sends OTP codes, acknowledgements & admin notificationswebklex/laravel-imap

How a ticket is submitted (web)

Employee → Routing / Middleware → Controller → Policy check → Model → Database, then Model → Controller → View → back to the browser.

How a ticket arrives by email

Email Sender → Gmail (IMAP) → Email Service → Model → Database, then an acknowledgement is sent back via SMTP.
