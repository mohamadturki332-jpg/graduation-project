System Design · Block Diagram

IT Help Desk Ticket System — System Architecture

A high-level block diagram of the system's building blocks and how a request flows through them. The application follows Laravel's layered MVC structure: the browser talks to server-rendered pages, every request passes through security middleware into a controller, controllers ask a policy for permission and use Eloquent models to reach the database, and a separate background pipeline turns inbound email into tickets and sends outbound mail.

Figure 5.6 — Asynchronous email pipeline: inbound mail becomes a ticket; outbound notifications are queued and sent via SMTP.

Reading the diagram: solid tiers are the layers of one Laravel application — the same framework hosts the controllers, policies, models, and the console commands. MySQL and the local file disk are the only persistent stores. Gmail (IMAP in, SMTP out) is the sole external dependency, reached only through the background pipeline so that a slow or offline mail server never delays a user's page.
